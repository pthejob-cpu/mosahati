# نشر «مساحتي» كموقع حقيقي

## محتويات الحزمة
- `index.html` الموقع كله (واجهة + اختبارات + ألوان + رياضة + مشاريع).
- `privacy.html` و `terms.html` و `about.html` و `404.html` صفحات قانونية وتعريفية.
- `manifest.webmanifest` و `sw.js` و `icons/` لتثبيت الموقع كتطبيق وعمله بدون إنترنت.
- `og-image.png` صورة المعاينة عند مشاركة الرابط، و `robots.txt`.

## 1) قبل النشر: استبدلي هذه القيم
| أين | ماذا |
|---|---|
| `privacy.html` و `terms.html` و `about.html` | تم: البريد مضاف ✅ |
| `index.html` (`ADMIN_WA`) | تم: رقم واتساب التسجيل مضاف ✅ |
| `index.html` (دالة `temu` وبطاقات `AFFILIATE`) | روابط الأفيليت الحقيقية بعد قبولك في برنامج الشركاء |
| `index.html` (مصفوفة `SHOPS`) | احذفي الأمثلة التجريبية وأضيفي مشاريع حقيقية |
| `index.html` (وسم `og:image`) | بعد معرفة العنوان اجعليه رابطاً كاملاً مثل `https://عنوانك/og-image.png` |

## 2) النشر على GitHub Pages (مجاني)
1. أنشئي حساباً على github.com ثم مستودعاً جديداً (Public) باسم مثل `mosahati`.
2. ارفعي كل ملفات الحزمة (مع مجلد `icons`) إلى جذر المستودع.
3. من Settings ثم Pages: اختاري Branch: `main` و Folder: `/ (root)` ثم Save.
4. بعد دقيقة يصبح الموقع على `https://اسمك.github.io/mosahati/`.

## 3) نطاق خاص (اختياري)
- اشتري نطاقاً (مثل mosahati.com) وفي Pages أضيفي النطاق وفعّلي Enforce HTTPS، وأضيفي سجل CNAME عند مزوّد النطاق.

## 4) اختبار بعد النشر
- افتحيه على هاتفك وجرّبي كل قسم، ثم «إضافة إلى الشاشة الرئيسية».
- فعّلي وضع الطيران وأعيدي فتحه: يجب أن يعمل.
- شاركي الرابط على واتساب وتأكدي من ظهور الصورة والعنوان.

## 5) عند كل تحديث كبير
غيّري `const V = 'mosahati-v1'` في `sw.js` إلى `v2` ثم `v3`... وإلا تبقى بعض المستخدمات على النسخة القديمة المخزنة.

## 6) المرحلة التالية: مجتمع ومشاريع حقيقية
الاستضافة الثابتة لا تحفظ بيانات مشتركة. المقترح: Supabase (مجاني للبداية)
- حسابات، جداول (منشورات، تعليقات، مشاريع، بلاغات)، وقواعد أمان تجعل الخاص خاصاً فعلاً.
- تخزين صور، وزر إبلاغ، ومراجعة قبل نشر المشاريع.
- أحتاج منك: مشروع Supabase جديد، ورابطه ومفتاحه العام (anon key). هذا المفتاح آمن للنشر في الواجهة بشرط تفعيل قواعد الأمان.

## 7) تنبيهات مهمة
- نصوص الخصوصية والشروط قوالب عامة وليست استشارة قانونية. يُنصح بمراجعتها محلياً، وحدّدي الفئة العمرية (كتبتُ 13 سنة فأكثر).
- أضيفي الإفصاح عن العمولة (موجود في أسفل الموقع) وراجعي شروط برنامج الأفيليت.
- الخطوط تُحمَّل من Google Fonts. لخصوصية أفضل يمكن لاحقاً استضافتها محلياً.
- المحتوى النفسي إرشادي. أضيفي لاحقاً رقماً أو جهة مساعدة محلية موثوقة تتحققين منها بنفسك.
